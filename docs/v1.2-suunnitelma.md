## 1. Ehdollinen kenttänäkyvyys — **Done**

Lomakekentälle voi asettaa ehdon **Näytä vain jos…**.

Kun ehto ei täyty, kenttä:

1. ei näy wizardissa  
2. ei ole pakollinen  
3. ei syötä arvoa kaavakontekstiin eikä aja efektejä  
4. ei näy yhteenvedossa / snapshotin display-riveissä  

Piilotetun kentän aiempi arvo säilyy draftissa / `form_snapshot.fieldValues`-tallenteessa.

### 1.1 Malli

```ts
interface FieldVisibilityCondition {
  fieldKey: string;
  operator?: 'eq' | 'neq' | 'gt' | 'lt' | 'gte' | 'lte';
  value: string; // boolean: "true"|"false"; select: option.value; number: "10" / "10,5"
}
```

- **eq / neq:** boolean, select, number  
- **gt / lt / gte / lte:** vain number-lähde (numeerinen `parseNumber`)  
- **Todo (ei Conflicts):** AND/OR-ehtoryhmät

## 2. Kaavafunktiot — **Done** (v1.2)

```
min(a, b, …)   max(a, b, …)   round(x) | round(x, n)   if(ehto, sitten, muuten)
```

Vertailut ehtoon: `>` `<` `>=` `<=` `==` `!=` (tulos 1/0). Boolean-kenttä kontekstissa 0/1.

Kaavoissa desimaalierotin on `.` (pilkku on argumenttierotin).

## 5. Laskelman muokkaus – fieldValues

Tallennus (`buildFormSnapshot`): display-rivit + **raaka** `fieldValues` (sis. piilotetut ja computed-ylikirjoitukset).  
Muokkaus (`calculationToFormState`): palauttaa `formSnapshot.fieldValues` wizardiin.  
Vanhat tallenteet ilman `fieldValues`: vain kesto / asiakas / tuoterivit.

---

## 6. Versionvaroitus

- Jokainen lomakepohjan tallennus editorista (`saveFormDefinition`) kasvattaa `FormDefinition.version`-kenttää.  
- Tuonti, oletuspalautus ja ensiasennus käyttävät `preserveVersion: true`.  
- Muokatessa laskelmaa, jos `formSnapshot.formVersion !== form.version`, näytetään suomenkielinen varoitus (wizard + historia).  
- Vanhat tallenteet ilman snapshotia: ei varoitusta.

---

## 7. Kentän luonti, kopiointi ja Asiakas-sivu

- **Uusi kenttä:** tyyppi + valinnainen sivu (sis. Asiakas). Siirtyminen editoriin `?draft=1` -parametrilla; `db.saveFormDefinition` vasta Tallenna.
- **Kopiointi:** sama draft-polku (`duplicateFrom`). Hylkää / poistuminen tallentamatta ei jätä kopiota Kentät-listaan.
- **Tallentamattomat muutokset:** `useUnsavedChangesGuard` kysyy aina, kun editorissa on tallentamatonta (uusi kenttä on dirty heti).
- **Asiakas-sivu:** wizard näyttää kiinteät asiakastiedot + sivulle sijoitetut kentät. Validointi vaatii nimen ja sivun pakolliset extra-kentät.
