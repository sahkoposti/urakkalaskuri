## 1. Ehdollinen kenttänäkyvyys

Lomakekentälle voi asettaa ehdon **Näytä vain jos…**. Esimerkki:

- Kenttä `raystaan_aluset_ja_otsalaudat` (Kyllä/Ei)
- Kenttä `raystasmetrit` (numero) → **Näkyvyysehto:** `raystaan_aluset_ja_otsalaudat` = Kyllä

Kun ehto ei täyty, kenttä:

1. ei näy wizardissa
2. ei ole pakollinen (validointi ohittaa)
3. ei syötä arvoa kaavakontekstiin eikä aja efektejä
4. ei näy yhteenvedossa / `form_snapshot`-kentissä

Piilotetun kentän aiempi arvo säilyy draftissa (jos käyttäjä vaihtaa ehdon takaisin päälle), mutta sitä ei käytetä laskennassa.

### 1.1 Malli

```ts
interface FieldVisibilityCondition {
  fieldKey: string;          // riippuvan kentän key
  operator?: 'eq' | 'neq';   // oletus eq
  value: string;             // boolean: "true"|"false"; select: option.value
}

// FormField.showWhen?: FieldVisibilityCondition
```

Ketjutus: jos riippuvuuskenttä on itse piilotettu, myös riippuva kenttä piilotetaan.

### 1.2 Konfigurointi (UI)

Lomakeasetukset → Kentät → [kenttä] → **Näkyvyysehto**

1. Kytke „Näytä vain jos ehto täyttyy”
2. Valitse riippuva Kyllä/Ei- tai valintalistakenttä
3. Valitse vertailu (Yhtä kuin / Eri kuin) ja arvo
