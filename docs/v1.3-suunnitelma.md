# Urakkalaskuri – Versio 1.3

> **Tila:** Seuraava versio (suunnittelu)  
> **Nykyinen sovellus:** [sovellus.md](./sovellus.md) (v1.2.4)  
> **Edeltäjä:** [v1.2](./v1.2-suunnitelma.md)  
> **Arkisto:** [v1](./archive/v1-suunnitelma.md), [v1.1](./archive/v1.1-suunnitelma.md)

Versio 1.3 tuo **PDF-tulostuksen** kahdella erillisellä asiakirjalla:

1. **Tarjous** – asiakkaalle annettava hintatarjous (eritelty hinta + materiaalit + kotitalousvähennys)  
2. **Urakkakortti** – maalarille / työmaalle annettava työohje (vain työ, ei hintoja)

PDF generoidaan laskelman erittelysivulta (historia **ja** heti **Laske**-painikkeen jälkeen). Nykyinen v1.2.4 tallentaa laskelman jo Laske-hetkellä ja avaa saman erittelysivun; erillistä „yhteenveto ennen tallennusta” -näyttöä ei ole.

---

## Vahvistetut päätökset

| Aihe | Päätös |
|------|--------|
| **Tarjouksen hinta** | Selkeä erittely: työ, materiaalit (rivit + summat, **ei kate-/palkkioerittelyä**), ALV, kokonaishinta |
| **Kotitalousvähennys** | Tarjouksessa erillinen laskelma **yksityisasiakkaalle** (työn osuus, vähennys %, vähennyksen jälkeinen kustannus) |
| **Urakkakortti** | Vain työ: kesto, miehistö, lomaketiedot, materiaalimäärät (tuote + määrä + yksikkö). **Ei** materiaalihintoja, **ei** kokonaishintoja |
| **Tarjousnumero** | Juokseva numero; **ensimmäinen numero** asetettavissa asetuksista |
| **PDF erittelystä** | Kyllä – sama näkymä heti Laske-jälkeen ja historiasta |
| **Voimassaoloaika ja ehdot** | Muokattavat asetuksissa |

## Tavoite

| Asiakirja | Kenelle | Tarkoitus |
|-----------|---------|-----------|
| **Tarjous-PDF** | Asiakas | Eritelty hintatarjous, materiaalilista, kotitalousvähennys (yksityinen), voimassaolo ja ehdot |

- **Historia** → laskelman tiedot → „Luo tarjous-PDF” / „Luo urakkakortti-PDF”
- **Laske-jälkeinen erittely** → samat painikkeet (laskelma on jo tallennettu v1.2.4:ssä)

|-------|------------------|
| `projectName`, `customer` | Nimi, puhelin, sähköposti, osoite, postinumero, postitoimipaikka, lisätiedot, tyyppi, käänteinen ALV |

## 1. Tarjous-PDF (asiakas)

### 1.1 Sisältö

**Ylätunniste**

- ColoRajaton-logo
- Yrityksen yhteystiedot (asetuksista, ks. §4)
- Otsikko: **Tarjous**
- Päivämäärä
- **Tarjousnumero** (juokseva, esim. `1042`)

**Asiakas**

- Nimi, osoite, postinumero, postitoimipaikka, puhelin, sähköposti
- Asiakastyyppi
- Yritysasiakkaalle: käänteinen ALV -maininta tarvittaessa

**Työn kuvaus**

- `formSnapshot.fields` ryhmiteltynä sivuotsikoittain

**Hinta – eritelty (ei kate-/palkkio-rivejä)**

| Rivi | Lähde | Näyttö |
|------|-------|--------|
| Työ (urakka) | `contractPriceVat0` | Yksityinen: alv; yritys: alv0 |
| Materiaalit | `lines[]` + `materialsVat0` | Rivitaulukko: tuote, määrä, yksikkö, yksikköhinta, rivisumma; yhteensä |
| ALV | `vatAmount`, `vatPercent` | Yksityinen: erittely; yritys: normaali tai käänteinen ALV |
| **Kokonaishinta** | `totalPriceVat0` / `totalPriceVat` | Korostettu |

Materiaalit näytetään **suoraan laskelman hinnoilla** – asiakas näkee materiaalikustannukset, ei sisäistä myyntikatetta.

**Kotitalousvähennys** (vain `customerType === 'private'`)

Erillinen lohko tarjouksen loppuosassa:

| Rivi | Laskenta |
|------|----------|
| Työn osuus (alv) | Urakkahinta + ALV = `applyVat(contractPriceVat0, vatPercent)` |
| Kotitalousvähennys (X %) | `työn osuus × kotitalousvähennysProsentti / 100` (prosentti asetuksista, oletus 40 %) |
| Arvioitu kustannus vähennyksen jälkeen | `kokonaishinta (alv) − kotitalousvähennys` |

Huomautusteksti PDF:ssä (asetuksista tai oletus): vähennys on henkilökohtainen veroetu, enimmäismäärät vuodessa, materiaalit eivät ole vähennyskelpoisia.

Yritysasiakkaalle: kotitalousvähennys-lohkoa **ei näytetä**.

**Alatunniste**

- Voimassaoloaika: „Tarjous voimassa X päivää” (`offerValidDays` asetuksista)
- Ehdot (`offerTermsText` – monirivinen, muokattava asetuksissa)
- „Terveisin, [yrityksen nimi]”

### 1.2 Ulkoasu

- A4, pysty
- IBM Plex Sans (web-safe fallback)
- Teeman accent-väri otsikoihin
- Selkeät taulukot: materiaalirivit, hintaerittely, kotitalousvähennys

## 2. Urakkakortti-PDF (maalari)

### 2.1 Sisältö (vain työ)

**Ylätunniste**

- Otsikko: **Urakkakortti**
- Päivämäärä
- Kohde: asiakkaan nimi + osoite
- Yhteyshenkilön puhelin

**Työn toteutus**

- Työn arvioitu kesto (pv) – sama säävaraus + ceil kuin erittelyssä
- Työryhmän koko (hlö)
- Lomaketiedot (`formSnapshot.fields`)

**Materiaalit**

- Taulukko: **tuote | määrä | yksikkö**  
- Ei yksikköhintoja, ei rivisummia, ei materiaalien yhteissummaa

**Huomiot**

- Asiakkaan lisätiedot
- Vapaa muistiinpanoalue (viivat)

### 2.2 Mitä EI näytetä

| Ei urakkakortissa |
|-------------------|
| Materiaalien hinnat tai summat |
| Kokonaishinta (asiakas tai muu) |
| Urakkahinta / työn hinta |
| ALV-erittely |
| Myyntikate / myyntipalkkio |
| Kotitalousvähennys |

Urakkakortti on puhtaasti **työmaan työohje**, ei hinnoitteludokumentti.

## 3. Kotitalousvähennys (uusi laskentamoduuli)

Toteutus: `src/core/pdf/kotitalousDeduction.ts` (tai `src/core/calculation/` jos jaetaan muualla).

```ts
interface KotitalousDeductionInput {
  contractPriceVat0: number;
  totalPriceVat: number;
  vatPercent: number;
  deductionPercent: number; // asetuksista, oletus 40
}

interface KotitalousDeductionResult {
  workShareVatIncluded: number;   // työn osuus alv
  deductionAmount: number;        // vähennys €
  estimatedCostAfterDeduction: number;
}
```

**Säännöt v1.3:**

- Vain yksityisasiakas
- Vähennys lasketaan **työn osuudesta (alv)**, ei materiaaleista
- Prosentti muokattavissa asetuksissa (`kotitalousDeductionPercent`, oletus **40**)
- Vuosi-enimmäismäärät: informatiivinen huomautusteksti PDF:ssä (ei estä laskentaa v1.3:ssa)

Yksikkötestit: työ + materiaalit + ALV → oikea vähennys ja jälkeinen kustannus.

## 4. Tarjousnumero (juokseva)

### 4.1 Asetukset

```ts
interface PdfSettings {
  offerNumberStart: number;    // ensimmäinen numero, oletus esim. 1000
  offerValidDays: number;      // oletus 14
  offerTermsText: string;      // monirivinen ehdot-teksti
  kotitalousDeductionPercent: number; // oletus 40
}
```

`nextOfferNumber` tallennetaan SQLiteen (asetukset). Alustus: `nextOfferNumber = offerNumberStart` kun asetusta muutetaan tai ensiasennuksessa.

### 4.2 Numeron myöntö

1. Kun **tarjous-PDF** luodaan ensimmäisen kerran tälle laskelmalle → myönnetään `nextOfferNumber`, kasvatetaan laskuria, tallennetaan laskelmalle `offerNumber`
2. Uudelleen tulostettaessa samaa laskelmaa → **sama numero** (ei uutta juoksevaa)
3. Ensimmäinen PDF heti Laske-jälkeen käyttää jo tallennettua riviä (sama kuin historiasta)

**Tietomalli:**

```ts
// CalculationRecord + wizardSession
offerNumber?: number;
```

Urakkakortti-PDF:ssä tarjousnumeroa **ei näytetä** (vain tarjouksessa).

## 6. Tekninen toteutus

### 6.1 Stack

```
HTML-malli → expo-print → PDF → expo-sharing
```

Paketit: `expo-print`, `expo-sharing`, `expo-file-system`.

### 6.2 Koodirakenne

```
src/core/pdf/
  types.ts
  kotitalousDeduction.ts
  buildPdfContext.ts          # CalculationRecord → PdfContext
  offerNumber.ts              # myöntö + persistointi
  renderTarjousHtml.ts
  renderUrakkakorttiHtml.ts
  generatePdf.ts
  pdfStyles.ts

src/components/pdf/
  PdfExportButtons.tsx

app/history/[id].tsx          # PdfExportButtons (Laske ohjaa tänne)
app/settings/pdf.tsx          # uusi asetussivu
```

### 6.3 PdfContext

```ts
interface PdfContext {
  kind: 'tarjous' | 'urakkakortti';
  record: CalculationRecord;
  customer: CustomerInfo;
  company: CompanyProfile;
  pdfSettings: PdfSettings;
  formFields: FormSnapshotField[];
  materialLines: CalculationLine[];
  kotitalous?: KotitalousDeductionResult;
  offerNumber?: number;
  generatedAt: Date;
}
```

`buildPdfContext(record, formDefinition, products, settings)` käyttää tallennettua laskelmaa – **ei duplikaattilogiikkaa hintojen formatoinnissa**. Laske ja historia käyttävät samaa näkymää.

### 6.4 Virhetilanteet

| Tilanne | Käyttäytyminen |
|---------|----------------|
| Vanha tallenne ilman `formSnapshot` | PDF: asiakas + hinnat + materiaalit; lomake „Ei lomaketietoja” |
| Ei materiaalirivejä | Materiaaliosio pois tai „Ei materiaalirivejä” |
| Yritysasiakas | Ei kotitalousvähennys-lohkoa |
| `expo-print` epäonnistuu | Alert |
