# Urakkalaskuri – Versio 1.3

> **Tila:** Seuraava versio (PDF) — tuoterakenteet on jo sovelluksessa  
> **Nykyinen sovellus:** [sovellus.md](./sovellus.md)  
> **Tuoterakenteet:** [tuoterakenteet.md](./tuoterakenteet.md)  
> **Edeltäjä:** [v1.2](./v1.2-suunnitelma.md)  
> **Arkisto:** [v1](./archive/v1-suunnitelma.md), [v1.1](./archive/v1.1-suunnitelma.md)

**Järjestys:** tuoterakenteet ja rivikohtainen yhteenveto ovat käytössä. Tämä dokumentti kuvaa **PDF-tulostusta** (tarjous, urakkakortti) ja siihen liittyviä yritys-/tarjousasetuksia.

Versio 1.3 tuo **PDF-tulostuksen** kahdella asiakirjalla:

1. **Tarjous** – asiakkaalle annettava hintatarjous (A4, niin monta sivua kuin sisältö vie). Pohja noudattaa erillistä asetteluluonnosta.  
2. **Urakkakortti** – maalarille / työmaalle. Näyttää **tekijöiden urakan**, ei muita hintoja.

Laskelma **tallentuu Yhteenveto-painikkeesta**. PDF:t on tarkoitus luoda yhteiseltä erittelysivulta (`CalculationDetailView`).

## Vahvistetut päätökset

| Aihe | Päätös |
|------|--------|
| **Tallennus** | **Yhteenveto** kirjoittaa SQLite-rivin heti. PDF käyttää `CalculationRecord`-riviä. |
| **Tulostuspaikka** | Erittelysivu: **Luo tarjous** ja **Luo urakkakortti**. |
| **Tarjouspohja** | Kiinteä HTML-asettelu (luonnos): ylätunniste → speksikortit → hinta → lisätiedot → alatunniste. Useita PDF-sivuja tarvittaessa. |
| **Speksit** | Lomakeasetukset → **Tarjous**: mitkä lomakesivut tulostetaan. Kentät = `showOnSummary` (ei järjestelmäkenttiä). |
| **Tarjousnumero** | Juokseva. Näkyy „Tarjouksen tiedot” -laatikossa yhdessä päiväyksen ja voimassaolon kanssa. Sama laskelma pitää saman numeron. |
| **Voimassaolo** | Asetuksista, oletus **31 pv**. PDF:ssä **päättymispäivä** (päiväys + pv). |
| **Lisätiedot** | Vain Tarjous-asetusten teksti. Ei asiakkaan `notes`-kenttää. |
| **Hintaerittely** | Yksityinen: alv0, ALV, hinta alv, ale %, loppusumma (alv). **Yritys ja käänteinen ALV: aina alv0** — ei „Hinta alv” -riviä, ei ALV-tekstiä. |
| **Kotitalousvähennys** | Vain yksityisasiakas. **Oma vakiopohja, tarjouksen viimeinen erillinen PDF-sivu.** Ei urakkakorttiin. |
| **Yritys** | Oma sivu **Asetukset → Yritys**. Logo Teema-sivulta. Footer: kolmisarakkeinen malli + sivunumero (ei logoa eikä myyjää footerissa). |

| **Debug** | Ei erillistä sivua. Kytkimet **Lomakeasetukset**-sivun alaosaan (JSON-toimintojen jälkeen). |
| **Urakkakortti** | Työohje + **tekijöiden urakka** (`contractPriceVat0`). Ei muita hintoja. |

## 1. Tarjous-PDF – asettelu (luonnos)

A4 pysty. Sisältö saa jatkua **niin monelle sivulle kuin tarvitaan**. Ylätunniste ja alatunniste toistuvat jokaisella PDF-sivulla (`@page` + HTML header/footer).

```
┌─────────┬────────────────────┬─────────────────────┐
│  LOGO   │  Asiakkaan tiedot  │  Tarjouksen tiedot  │
└─────────┴────────────────────┴─────────────────────┘
─────────────────────────────────────────────────────
┌──────────────────────┐  ┌──────────────────────┐
│ Sivu 1.              │  │ Sivu 2.              │
│ (speksirivit)        │  │ (speksirivit)        │
└──────────────────────┘  └──────────────────────┘
     … lisäkortit 2 sarakkeen ruudukossa, tarvittaessa seuraavalle PDF-sivulle …

  Hinta alv0          Hinta alv
  ALV                 Ale %
                      Loppusumma

  Lisätiedot:
  (vain Tarjous-asetusten teksti)

─────────────────────────────────────────────────────
Footer (3 saraketta + sivunumero, ks. §1.5):
  ColoRajaton Oy          www.colorajaton.fi         Y-tunnus: 3224017-2
  Toivonlinnantie 350     info@colorajaton.fi        Puh. +358 40 938 9403
  21500 Piikkiö                                                    Sivu 1/3

[sivunvaihto — vain yksityisasiakas]
┌─────────────────────────────────────────────────────┐
│  Kotitalousvähennys (vakiopohja, oma sivu)          │
└─────────────────────────────────────────────────────┘
```

### 1.1 Ylätunniste (joka PDF-sivu)

Kolme palstaa, vaakaviiva alle.

| Palsta | Sisältö |
|--------|---------|
| **Logo** | Yritys-asetusten logo (v1.3: ColoRajaton-tiedosto, sama `BrandLogo`; oman tiedoston valinta myöhemmin jos ei ehdi) |
| **Asiakkaan tiedot** | Nimi, osoite (+ postinumero ja -toimipaikka yhdelle riville), puhelin, sähköposti |
| **Tarjouksen tiedot** | **Tarjousnumero** (juokseva). Päiväys (generoinnin päivä). **Voimassa** päättymispäivään (päiväys + `offerValidDays`, oletus 31; esim. 10.10.2026). |

Asiakastyyppiä ei toisteta tässä laatikossa. Käänteistä ALV:ta ei merkitä tekstirivinä mihinkään (hinnat vain alv0).

### 1.2 Lomakesivujen speksit (ruudukko)

Vain sivut, jotka on merkitty päälle **Lomakeasetukset → Tarjous**.

Jokainen valittu sivu on **kortti**: otsikko = sivun nimi, alla speksirivit (`label` + arvo + yksikkö).

**Skaalaus (selkeys):**

| Tilanne | Asettelu |
|---------|----------|
| 0 speksisivua | Ruudukko pois; hintaerittely nousee ylätunnisteen alle |
| 1 sivu | Yksi kortti, täysi leveys |
| 2+ sivua | **Kaksi saraketta** (luonnos: Sivu 1 \| Sivu 2). Kolmas kortti aloittaa seuraavan rivin. |
| Paljon rivejä yhdessä kortissa | Kortti kasvaa alaspäin; `page-break-inside: avoid` kun mahtuu yhdelle PDF-sivulle, muuten rivi saa katketa |
| Paljon kortteja | Ruudukko jatkuu seuraaville PDF-sivuille; ylätunniste/footer pysyvät |

Typografia:

- Peruskoko ~11 pt, minimi ~9 pt
- Kortin sisällä ei pienennetä alle minimin – mieluummin lisää PDF-sivuja kuin ahdetaan
- Sarakkeiden leveys 50 % / 50 %, väli ~12 px
- Teeman accent kortin otsikossa tai reunassa

Järjestys = lomakkeen `sortOrder`. Tyhjä sivu (ei speksirivejä tällä laskelmalla) jätetään pois, jolloin ruudukko tiivistyy.

### 1.3 Hintaerittely

Kaksi palstaa, speksien alla. **Ei** kate-/palkkiorivejä. **Ei** työ/materiaalit-rivitaittoa (luonnos on kokonaishinta).

**Yksityisasiakas**

| Vasen | Oikea |
|-------|--------|
| Hinta alv0 → `totalPriceVat0` | Hinta alv → `totalPriceVat` |
| ALV → `vatAmount` (`vatPercent`) | Ale % → `discountPercent` (piiloon jos 0) |
| | **Loppusumma** → `totalPriceVat` (korostettu) |

**Yritysasiakas ja käänteinen ALV: aina alv0**

| Vasen | Oikea |
|-------|--------|
| Hinta alv0 → `totalPriceVat0` | Ale % → `discountPercent` (piiloon jos 0) |
| | **Loppusumma** → `totalPriceVat0` (korostettu) |

Ei „Hinta alv” -riviä, ei ALV-euromäärää, **ei** tekstiä „Käänteinen ALV”.

### 1.4 Lisätiedot

Otsikko **Lisätiedot:** ja sen alla **vain** Tarjous-asetusten monirivinen teksti. Asiakkaan `notes` ei tule tähän. Tyhjä kenttä → osio pois.

### 1.5 Alatunniste (joka PDF-sivu, myös KHV-sivu)

Kiinteä kolmen palstan asettelu (referenssikuva). Logo ja myyjän nimi **eivät** kuulu footeriin (logo on ylätunnisteessa).

```
ColoRajaton Oy              www.colorajaton.fi         Y-tunnus: 3224017-2
Toivonlinnantie 350         info@colorajaton.fi        Puh. +358 40 938 9403
21500 Piikkiö                                                    Sivu 1/3
```

| Palsta | Rivit | Lähde |
|--------|-------|--------|
| Vasen | Nimi, katuosoite, postinumero + postitoimipaikka | `companyName`, `address`, `postalCode` + `postalLocality` |
| Keskellä | Www, sähköposti | `website`, `email` |
| Oikea | `Y-tunnus: …`, `Puh. …` | `businessId`, `phone` |

**Sivunumero:** oikealla alhaalla, kursivoitu, muoto **`Sivu 1/3`** (nykyinen / kokonaismäärä). Sama kaikilla tarjous- ja KHV-sivuilla.

Typografia: IBM Plex Sans, musta, palstat vasemmalle tasattu; sivunumero oikealle. Tyhjä kenttä: rivi pois, palsta ei näytä paikanpitäjää.

Toteutus: print-CSS (`counter(page)` / `counter(pages)`) tai `expo-print`:n sivumarginaalit. **Tarkistetaan laitteella** — WebView ei aina tue `counter(pages)`:ää; jos kokonaismäärä puuttuu, ensisijainen korjaus on footer-HTML + print-asetukset, ei `Sivu n` ilman nimittäjää.

### 1.6 Kotitalousvähennys – viimeinen erillinen sivu

Vain kun `customerType === 'private'`. Yritysasiakkaalle sivua **ei** lisätä.

Sivunvaihto: `page-break-before: always`. **Oma vakiopohja** (kiinteä HTML, ei käyttäjän muokattava asettelu). Sama ylätunniste (logo, asiakas, tarjouksen tiedot) ja sama footer kuin muilla tarjoussivuilla, jotta liite kuuluu samaan asiakirjaan.

**Runko (vakiopohja):**

| Rivi | Laskenta |
|------|----------|
| Otsikko | Kotitalousvähennys |
| Työn osuus (sis. ALV) | `applyVat(contractPriceVat0, vatPercent)` |
| Kotitalousvähennys (X %) | `työn osuus × kotitalousDeductionPercent / 100` (oletus 40 %) |
| Materiaalit | ei vähennyskelpoisia (maininta, ei erillistä vähennystä) |
| Arvioitu kustannus vähennyksen jälkeen | `totalPriceVat − vähennys` |

Huomautus (asetuksista tai oletusteksti): vähennys on henkilökohtainen veroetu, vuosikohtaiset enimmäismäärät, arvio ei ole verottajan päätös.

Prosentti ja huomautusteksti: **Lomakeasetukset → Tarjous**.

Toteutus: `src/core/pdf/kotitalousDeduction.ts` + `renderKotitalousPageHtml.ts`, liitetään tarjous-HTML:n loppuun.

## 2. Urakkakortti-PDF (maalari)

Kiinteä malli, ei Tarjous-sivun sivuvalintaa. Spekseiksi **kaikki** sisältösivut (`showOnSummary`).

### 2.1 Sisältö

- Otsikko **Urakkakortti**, päivämäärä, kohde (nimi + osoite), puhelin
- **Tekijöiden urakka** = rivin `contractPriceVat0` (alv0) – ainoa hinta. Jos lomaketta ei käytetty, urakka on 0 kunnes se **kirjataan manuaalisesti urakkakorttia luodessa**.
- Työn arvioitu kesto (säävaraus + ceil), työryhmän koko
- Lomaketiedot (kaikki sisältösivut)
- Materiaalit: tuote \| määrä \| yksikkö (ei hintoja)
- Asiakkaan lisätiedot + muistiinpanoalue

### 2.2 Mitä EI näytetä

Materiaalien hinnat, asiakkaan kokonaishinta, ALV, kate, palkkio, kotitalousvähennyssivu, tarjouksen voimassaolo / lisätiedot-teksti.

## 3. Mitkä speksit tarjoukseen

Lomake laskee, **Lomakeasetukset → Tarjous** valitsee mitä asiakas näkee.

| Missä | Mitä |
|-------|------|
| **Kentät** | Mitkä kentät ovat speksejä (`showOnSummary`) |
| **Tarjous** | Mitkä **sivut** tulostetaan tarjouksen ruudukkoon |

```ts
interface OfferPageInclusion {
  pageId: string;
  enabled: boolean;
}
```

Oletus kun sivu ilmestyy listaan:

| Sivu | Tarjouksessa | Miksi |
|------|----------------|--------|
| Sisältösivu, vähintään yksi speksi | päällä | esim. Pinta-alat |
| `system: "customer"` | pois | yhteystiedot ovat ylätunnisteessa |
| `system: "materials"` | pois | ei speksikorttia |
| Vain järjestelmäkenttiä (Hinnat, kesto) | pois | hinnat ovat hintaerittelyssä |

Oletuslomake: vain **Pinta-alat** päällä.

`syncOfferPages(form, settings)`: uusi sivu → oletus; poistettu → rivi pois; otsikko aina lomakkeesta.

## 4. Lomakeasetukset → Tarjous

Näyttö: `app/settings/calculation/offer.tsx`. Pinon otsikko **Tarjous**.

```ts
interface OfferSettings {
  offerValidDays: number;              // oletus 31; PDF:ssä päättymispäivä
  additionalInfoText: string;          // Lisätiedot, vain tämä teksti
  offerPages: OfferPageInclusion[];
  offerNumberStart: number;            // juoksevan numeron aloitus, esim. 1000
  kotitalousDeductionPercent: number;  // oletus 40
  kotitalousFootnoteText?: string;
}
```

Kentät UI:ssa:

1. Tarjousnumeron aloitus
2. Voimassaolo (pv), oletus 31 — esikatseluteksti: „Päättymispäivä lasketaan tarjouksen päiväyksestä”
3. Lisätiedot (monirivinen)
4. Kotitalousvähennys-% ja valinnainen huomautus (vain yksityisasiakkaan KHV-sivulle)
5. **Lomakesivut tarjouksessa** — kytkin per sivu

Ei kytkimiä ylätunnisteelle, hinnalle tai footerin osille – asettelu on kiinteä.

## 7. Tarjousnumero

Juokseva numero **Tarjouksen tiedot** -laatikossa (päiväys, päättymispäivä, numero).

```ts
nextOfferNumber: number;     // erillinen settings-avain pdf_next_offer_number
```

Alustus: `nextOfferNumber = offerNumberStart`. Jos aloitusnumero nostetaan nykyistä seuraavaa suuremmaksi, laskuri hyppää. Pienennys ei palauta käytettyjä numeroita (varoitus asetuksissa).

1. Ensimmäinen **tarjous-PDF** tälle `CalculationRecord.id`:lle → myönnä numero, kasvata laskuria, tallenna `offerNumber`
2. Uudelleentulostus → sama numero
3. Urakkakortti ei näytä eikä myönnä numeroa

```ts
// CalculationRecord
offerNumber?: number;
```

Päättymispäivä: `validUntil = generatedAt + offerValidDays` kalenteripäivinä (suomi: `10.10.2026`).

## 8. Kotitalousvähennys (laskentamoduuli)

Ei kuulu tarjouksen runkosivulle eikä urakkakorttiin. Liitetään tarjous-PDF:n **loppuun omaksi sivukseen** (§1.6) kun asiakas on yksityinen.

```ts
interface KotitalousDeductionInput {
  contractPriceVat0: number;
  totalPriceVat: number;
  vatPercent: number;
  deductionPercent: number;
}

interface KotitalousDeductionResult {
  workShareVatIncluded: number;
  deductionAmount: number;
  estimatedCostAfterDeduction: number;
}
```

- Vähennys **työn osuudesta (sis. ALV)**, ei materiaaleista
- Vuosi-enimmäismäärää ei leikata v1.3:ssa (vain huomautus)
- Yksikkötestit: työ + materiaalit + ALV → oikea vähennys ja jälkeinen kustannus
