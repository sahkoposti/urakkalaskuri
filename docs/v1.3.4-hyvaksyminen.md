## KaavaKalle: materiaalirivin muoto

Ilmoitus on tässä. Tätä haaraa ei ole lähetetty hänelle erikseen.

Tallennettu rakennerivi voi sisältää:

```json
{
  "id": "paint",
  "productName": "Nova 7",
  "quantity": 0,
  "source": "manual",
  "shades": [
    { "id": "g", "name": "G47", "quantity": 3, "unit": "l" },
    { "id": "x", "name": "505X", "quantity": 5, "unit": "l" }
  ]
}
```

- Paikka on edelleen rakennerivin `materialQuantities` (`structure_lines`-JSON). Ei uutta SQL-saraketta eikä lomakepohjan avainta.
- Jos `shades` puuttuu tai on tyhjä, rivi tulostuu kuten ennen: Tuote, Määrä, Yksikkö.
- Jos sävyjä on, tuote on otsikko ja jokainen sävy on oma rivi omalla määrällä ja yksiköllä. Yhtä sävyä ei kopioida kaikille maaleille.
- `savy_kuvaus` ja `savy_maalarinvalkoinen` eivät ole tämän repositorion JSON-pohjissa. Esitäyttö ei lue niitä eikä keksi niille määrää. Sisämaalauksen v4t on yhä käyttäjän tuoma pohja, ei tässä repossa.
- Nova 7 / G47 3 l / 505X 5 l on vain esimerkki. Se ei ole oletusrivi eikä kulutus.
- Tuotua Maali-laatikkoa ei täytetä automaattisesti samoilla sävyillä. Käyttäjän muu materiaaliteksti säilyy.
- Kaavoja, hintoja ja tuotuja JSON-pohjia ei ole muutettu.

## Rajat

- Ei Android-ajoa, ei esikatselun lupadialogia, ei oikeaa `content://`-logoa, ei puhelua. Tätä haaraa ei ole hyväksytty itsenäisenä QA:na.
- Luonnos kirjoitetaan, kun käyttäjä poistuu laskennasta tai sovellus saa `background`/`inactive`-tilan, ja lomakkeessa on tallentamatonta sisältöä. Jokaista näppäilyä ei kirjoiteta.
- Jos prosessi kuolee ennen näitä tapahtumia, viimeisen onnistuneen tallennuksen jälkeiset näppäilyt katoavat. Android ei aina toimita taustatapahtumaa pakotetussa pysäytyksessä.
- Tyhjäksi pyyhittyä lomaketta ei kirjoiteta edellisen tallennetun rivin päälle. Viimeinen onnistunut tallennus jää.
- Asiakkaan tai tuoterakenteen lomakkeen avaus tallentaa session heti, myös ennen kuin käyttäjä muuttaa kenttää.
- Chrome-PDF ei ole `expo-print`. Sivunvaihto voi erota puhelimesta.
- Kaksi Lisätiedot-otsikkoa tarjouksessa on tarkoituksellinen: rakenteen teksti ennen hintoja, yrityksen teksti hintojen jälkeen.
